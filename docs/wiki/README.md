# AIHelper Wiki

프로젝트의 기능, 구조, 용어 및 의사결정을 LLM과 개발자가 함께 이해할 수 있도록 정리하는 지식 저장소입니다.

## 문서 작성 원칙

- 문서 하나에는 가능한 한 하나의 주제를 다룹니다.
- 파일명은 내용을 알 수 있는 영문 kebab-case를 사용합니다.
- 확인된 사실과 추정 또는 제안을 구분합니다.
- 관련 코드 경로와 `../raw` 원본 자료를 상대 경로로 연결합니다.
- 기능이나 아키텍처가 변경되면 관련 문서를 함께 갱신합니다.

## 문서 템플릿

```markdown
# 제목

## 요약

## 상세 내용

## 관련 코드

## 출처

- [원본 자료](../raw/example.md)

## 미결 사항
```
